ID Photo Cropper — Browser Test Prototype

1. Extract this ZIP.
2. Open ID_Photo_Cropper_Test.html in Chrome or Edge.
3. Select multiple photos using the file picker.
4. Use Process All, Edit crop, Remove BG, Save PNG, or Download All PNGs (ZIP).

No installer, Python, API key, or internet connection is required to open the test.

Important limits:
- This is a test prototype, not a Windows EXE and not a copy of your Cloud AI tool.
- It includes bulk upload, configurable output dimensions (default 300×378), per-photo zoom/position, PNG export, and ZIP export.
- Background removal is a simple edge-connected colour algorithm, NOT AI segmentation. It may not remove curtains, patterned backgrounds, or colours similar to the person. For reliable complex-background removal, an offline AI segmentation model needs to be integrated.
- Please test with copies of photos and check results before using for customer orders.
